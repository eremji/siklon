# Politique de sécurité

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique. Utilisez « Report a vulnerability » dans l'onglet
**Security** du dépôt : le signalement reste privé jusqu'à sa correction.

Merci d'indiquer la description du problème, les étapes pour le reproduire et son impact.

## Versions maintenues

Seule la branche `main`, celle qui est déployée, reçoit les correctifs de sécurité.

## Périmètre

L'application Siklon et ce dépôt. Les données du NHC, de la NOAA et de Météo-France
relèvent de leurs producteurs.
